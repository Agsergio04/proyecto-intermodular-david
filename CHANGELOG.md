# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-12

### Added

- User authentication system with JWT (register, login, logout)
- AI-powered interview sessions using Google Gemini
- Real-time AI feedback and question generation
- User dashboard with interview statistics and charts
- Subscription system with PayPal integration
- Internationalization support (i18n) with multiple languages
- Dark and light theme support
- Responsive design with Tailwind CSS
- Docker containerization with Docker Compose
- MongoDB database with Mongoose ODM
- Security features: Helmet.js, CORS, rate limiting
- RESTful API with Express.js
- Deployment configuration for Render platform
